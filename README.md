A mobile app that connects students who need something done on campus with others willing to help — think food pickups, printouts, library runs. Built with real-time tracking and instant notifications.

A full-stack web portal for the university's international affairs office, handling dynamic content management, a gallery, fee/scholarship info, grants, and a contact system. Includes an admin panel with CRUD operations.
